## 🌟 نبذة عن المشروع ورسالته

انطلقت هذه المنصة بمبادرة نوعية من **الأستاذ محمد عدايكة** (أستاذ مادة الرياضيات بمتوسطة المجاهد باهي علي - ولاية الوادي)، حيث طُوّرت في نسختها الأولى لتكون سبورة رقمية نموذجية لكراريس وتطبيقات وأعمال التلاميذ. 

وبعد الزيارة التوجيهية لمفتش مادة الرياضيات وإعجابه الشديد بالفكرة وعائدها البيداغوجي المباشر على تحصيل التلاميذ وانضباطهم، تقرر **تعميم المنصة على كامل مقاطعات ولاية الوادي الخمس** لتتحول من موقع شخصي إلى **منصة ولائية شاملة متعددة الحسابات** تجمع:
1. **الأساتذة (Teachers):** مساحة سحابية لرفع صور السبورة، كراس الدروس، الأعمال الموجهة، السلاسل، التقييم الميداني، والتواصل مع المفتش.
2. **الأولياء والتلاميذ (Parents & Students):** فضاء مباشر بدون تسجيل، يتيح للولي متابعة أساتذة أبنائه وحل الواجبات المنزلية ولوحة الشرف وساعات الاستقبال بلمسة زر.
3. **مفتشو الولاية (Inspectors):** لوحة قيادة تغطي المقاطعات الخمس لمتابعة نشاط الأساتذة، فحص المذكرات البيداغوجية، وإرسال المناشير والندوات التكوينية.
4. **المشرف العام (Super Admin):** لوحة إدارة مركزية لترقية وتعيين المفتشين وتوثيق الحسابات ومراقبة النظام.

> 💎 **القاعدة الذهبية لتصميم وتطوير المنصة:**  
> «البساطة والسهولة المطلقة في الاستخدام مع توفير أقوى الأساسيات — دون تعقيد للولي (بدون تسجيل)، دون أعباء تقنية على الأستاذ (ضغط فائق للصور)، وبأعلى خصوصية ودقة للمفتش».

1. **المقاطعة الأولى (الوادي 1):** متوسطات وسط مدينة الوادي والبلديات المجاورة.
2. **المقاطعة الثانية (الوادي 2):** متوسطات جنوب وشرق الولاية.
3. **المقاطعة الثالثة (قمار):** متوسطات دائرة قمار والبلديات التابعة لها.
4. **المقاطعة الرابعة (الرقيبة):** متوسطات دائرة الرقيبة والبلديات التابعة لها.
5. **المقاطعة الخامسة (الدبيلة والمقرن):** متوسطات دوائر الدبيلة والمقرن وحاسي خليفة.

## 🚀 البدء السريع والتشغيل المحلي (Quick Start)

### 1. المتطلبات الأساسية
- **Node.js:** الإصدار 18.18 أو أحدث (يُفضل 20 LTS أو 22).
- **حزمة إدارة الحزم:** `npm` أو `pnpm`.
- **حساب Supabase:** مشروع مفعل مع قاعدة بيانات PostgreSQL وStorage Buckets.

### 2. تثبيت التبعيات
```bash
git clone https://github.com/adaikamohammed/math-eloued.git
cd math-eloued
npm install
```

### 3. إعداد متغيرات البيئة (`.env.local`)
أنشئ ملفاً باسم `.env.local` في المجلد الرئيسي وضع فيه:
```env
NEXT_PUBLIC_SUPABASE_URL=https://taoagpwjytgbjhbtnfps.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
# أو
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your_supabase_publishable_key
```

### 4. تشغيل خادم التطوير المحلي
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

### 5. بناء المشروع للإنتاج والتحقق من الأنواع
```bash
npm run build
```

## 🌐 النشر على Vercel (Production Deployment)

1. اربط مستودع GitHub مع [Vercel](https://vercel.com).
2. في إعدادات المشروع **Settings > Environment Variables**، أضف:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
3. قم بعمل Deploy، وستعمل المنصة مباشرة مع دعم شهادات SSL والتوزيع الجغرافي السريع CDN.
